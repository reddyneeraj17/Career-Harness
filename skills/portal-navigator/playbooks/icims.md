# iCIMS playbook

## Detect
- URL on `*.icims.com`; "iCIMS" in the footer or page title.

## Field mapping
- Requires an iCIMS profile/account; multi-step wizard (profile → resume → questions → review).
- Upload the resume early; the wizard prefills fields — verify every prefilled value.

## Submit button
- "Submit" on the final review step.

## Confirmation
- Capture "Your profile has been submitted" or the candidate dashboard status "Submitted". Screenshot it.

## Known quirks
1. Account creation may demand SMS verification — park for manual completion, never bypass.
2. Long wizard — screenshot every page. The back button loses state, so never use it.
3. Sessions expire aggressively — complete in one pass, or park with a checkpoint.
