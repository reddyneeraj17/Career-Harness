# Greenhouse playbook

## Detect
- URL on `boards.greenhouse.io` or `job-boards.greenhouse.io`, or a "Powered by Greenhouse" badge.

## Field mapping
- Single-page form: First/Last name, Email, Phone, Resume upload, then custom questions.
- Resume parsing fills fields — verify each one against the variant facts; never invent.

## Submit button
- "Submit Application" at the bottom of the form.

## Confirmation
- Capture "Your application has been submitted" / "Thanks for applying". Screenshot it.

## Known quirks
1. EEO / demographic questions are optional — decline, never fabricate.
2. Some boards ask for a LinkedIn URL in a specific field — leave blank rather than invent.
3. PDF size limit ~5MB — tailored PDFs are well under; hash-verify before upload per protocol.
