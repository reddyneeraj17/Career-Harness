# Lever playbook

## Detect
- URL on `lever.co` / `jobs.lever.co`; "Powered by Lever" in the footer.

## Field mapping
- Name, Email, Phone, Resume upload, optional cover letter (skip — never auto-write cover letters), custom questions.
- "How did you hear about us" dropdown → answer from profile facts, or hold via approval.

## Submit button
- "Submit application" at the bottom of the form.

## Confirmation
- Capture "Your application was submitted" / "Thanks for your application". Screenshot it.

## Known quirks
1. The EEO survey is a separate post-submit page — skip it; the application is already submitted.
2. Verify the filename shown after upload matches our tailored PDF before proceeding.
3. Location fields sometimes prefill the wrong country — correct from profile facts, never guess.
